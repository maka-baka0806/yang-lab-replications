# R20　合成 CT：用深度残差 U-Net 从单一 MR 生成 sCT

**原文**：J Appl Clin Med Phys 2026;27(1):e70343（DOI: 10.1002/acm2.70343）　**作者位次**：○ 合作者（第 6/9 作者）

**复现目标**：把 MR 转成可用于剂量计算的合成 CT；复现 DRU 的训练流程、图像质量评估（PSNR/SSIM/RMSE）与剂量学验证（Gamma 通过率），并检验「解剖先验」是否真的带来增益。

**与原论文的差异**：论文用 139 例真实患者（120 训练 / 19 测试）+ Visible Human 真实脑 CT 模板，并在真实 VMAT 计划上做 Gamma 验证；本复现用 60 例 32³ 合成体模，MR-CT 的强度关系由非线性映射模拟，Gamma 比对是把 HU 体数据当作「剂量图」做等价替换。因此**只能比较方法链条与增益方向**，不能与论文的 PSNR 75 dB / SSIM 0.99 等绝对值比较。

---

## 你会学到什么

- MR-only 放疗流程为什么需要合成 CT（少做一次 CT 定位）
- 深度残差 U-Net 的编码器-解码器 + 跳跃连接结构
- PSNR / SSIM / RMSE 三个图像质量指标的物理含义
- Gamma 指数如何被用来做「等价性」验证
- 消融实验怎么做：去掉解剖先验后性能如何变化

运行后终端会打印每一步的结果，并在 `reports/` 生成完整报告。

### 第 1 步　① 合成 CT 体模与配对 MR

对应论文数据：139 例患者的 T1 增强 MR。平台造头颅样体模（空气/头皮/颅骨/脑/脑室/病灶），再用**分段非线性映射 + 偏置场**生成配对 MR —— 关键是让骨在 MR 上呈低信号。

> 这一步刻意保留 MR-only 流程最难的环节：骨无法靠强度阈值还原。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 2 步　② 构建深度残差 U-Net（DRU）

对应论文 Method 的网络结构：编码器 + 残差块 + 转置卷积上采样 + 跳跃连接。

> 残差连接让「同位置强度重映射」这类任务更容易学。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 3 步　③ 训练 MR → sCT

对应论文的训练流程（DRU，患者特异 T1+C 输入）。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 4 步　④ 图像质量评估

对应论文报告的 PSNR / SSIM / RMSE / MAE。

> HU 域误差比归一化域误差更接近临床关心的问题。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 5 步　⑤ Gamma 指数等价性验证

对应论文把 sCT 送入计划系统重算、再用 Gamma 判据比对剂量分布的环节。

> 本复现做的是等价替换，验证的是**流程**而非剂量学精度。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

对应论文引入 Visible Human 健康脑 CT 作为解剖先验的设计。这里用训练集平均 CT 作为模板，比较单通道 vs 双通道。

> 先验的作用是补上 MR 看不到的骨信息。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。
