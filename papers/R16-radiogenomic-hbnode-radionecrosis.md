# R16　影像基因组学 HBNODE：脑转移放射性坏死 vs 肿瘤复发

**原文**：Med Phys 2025;52(4):2661-2674（DOI: 10.1002/mp.17635）　**作者位次**：○ 合作者（第 3 / 12 作者）

**复现目标**：把影像深度特征、基因组标志物与临床参数融合进一个 Heavy-Ball 神经 ODE 潜空间，复现「深度特征提取可建模为时空连续过程」这一假设，并验证三模态融合的判别能力优于任何单模态，同时导出可解释的潜空间诊断轨迹。

**与原论文的差异**：论文用真实脑转移 MRI 的深度特征与真实基因组 panel；本复现用三模态合成队列（32 维合成深度特征 + 4 个合成基因组标志物 + 3 项合成临床参数），模型被压到 6 维潜空间、40 个 epoch、CPU 训练，只报告 3 次分层划分的测试集 AUC。因此只比较「融合 vs 单模态」的方法学方向与轨迹可解释性，不比较绝对 AUC，也不复现原文的 LRP 归因图。

---

## 你会学到什么

- Heavy-Ball 动力学如何写成一个 ODE：dz/dt=v、dv/dt=−γv−∇U(z)+f(z,t)，以及为什么用 softplus 保证 γ>0、U 凸
- 手写 RK4 积分器：四阶精度、每步 4 次右端项求值，以及用「步长减半」验证积分器收敛性的做法
- 把「样本走向结论」写成潜空间轨迹后，如何用类间质心距离 / Fisher 比量化「结论何时形成」
- 多模态消融实验设计：每加一个模态看 AUC 增量，比只报告融合模型的 AUC 更有说服力
- 置换重要性（逐组打乱）如何在不打开黑箱的前提下回答「哪个模态不可替代」

## 逐步引导

```bash
cd yang-lab-replications
python code/run.py --id R16
```

运行后终端会打印每一步的结果，并在 `reports/` 生成完整报告。

### 第 1 步　① 造三模态合成队列（影像深度特征 + 基因组 + 临床）

对应原文的数据构成。三个潜在因子（影像 / 基因组 / 临床）在样本内正交化，结局由三者等权驱动并按分位数二值化（阳性率 45%）；影像 32 维里只有 12 维带信号，模拟冗余的深度特征。同时准备 3 次独立分层划分供后面求均值。

> 三源正交是刻意设计：这样「单模态 AUC 天花板」对三者相同，融合增益才有可比性。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 2 步　② 实现 HBNODE（重球动力学 + 手写 RK4）

对应原文的方法核心。编码器把输入映射到 (z₀, v₀)，再按 dz/dt=v、dv/dt=−γv−∇U(z)+f(z,t) 用 RK4 从 t=0 积分到 t=1，末态接线性分类头。本步检查结构与参数量，并用「步长减半的 RK4」和「单步欧拉」做积分器精度对照。

> softplus 保证阻尼 γ>0、势能 U(z)=½Σa_i z_i² 凸 —— −∇U 因此是稳定的回复力。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 3 步　③ 训练 HBNODE 并报告判别性能

对应原文的主结果。三模态输入（39 维）编码到 6 维潜空间，40 个 epoch、全批量 Adam、CPU 训练；在 3 次分层划分上各训练一次，报告测试 AUC 的均值与标准差。

> 每次划分只有 66 例测试样本，单次 AUC 的标准误约 0.07，所以必须看 3 次的均值和标准差。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 4 步　④ 导出潜空间诊断轨迹（分离度随演化时间变化）

对应原文的轨迹可视化。记录 t = 0, 0.125, …, 1 共 9 个时刻的 z(t)，计算两类质心距离、类内散布与 Fisher 分离比；并把分类头接到每个中间状态上，看判别能力在演化的哪一段形成。

> 这里要同时看两个指标：质心距离上升只说明状态在变，只有 Fisher 比上升才说明判别性在增强 —— 本复现里前者上升、后者持平。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 5 步　⑤ 多模态融合 vs 单模态消融

对应原文的融合必要性论证。固定同一套 3 次划分，比较 仅影像 / 影像+临床 / 影像+基因组 / 三模态全融合 四种输入的测试 AUC 与增量。

> 「每加一个模态 AUC 增加多少」比只报告融合模型的 AUC 更能说明多模态的必要性。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 6 步　⑥ 特征组置换重要性（可解释性）

对应原文用 LRP 做的可解释性分析。在测试集上逐组打乱特征后重新预测，记录 AUC 的平均下降：三个模态各一组，基因组内部再逐个标志物做一次，回答「哪个来源、哪个标志物不可替代」。

> 置换法只依赖模型的输入输出关系，不需要打开黑箱，是 LRP 归因图的实用替代品。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。

### 第 7 步　⑦ 结论对照

把复现得到的关键数字与原文的三条主张逐条对齐：融合优于单模态、深度特征提取可建模为连续过程、潜空间轨迹可解释。

> 合成数据只支持方向性结论；绝对 AUC 与真实临床场景没有可比性。

**你应该看到什么**：见 [报告](../reports/) 中对应章节。
